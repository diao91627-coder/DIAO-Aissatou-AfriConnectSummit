## Description du projet
AfriConnect Summit 2026 est un site web de présentation d'une conférence dédiée aux nouvelles technologies et à l'innovation en Afrique. Le site permet de découvrir le programme de l'événement, les intervenants, les sponsors et de s'inscrire en ligne.

## Technologies utilisées
- HTML5
- CSS3
- JavaScript
- Google Fonts
- Bootstrap Icons

## Fonctionnalités JavaScript implémentées
- Compte à rebours avant la conférence
- Mode sombre avec sauvegarde dans le Local Storage
- Compteurs animés
- Onglets du programme
- Filtrage dynamique des intervenants
- Validation du formulaire de contact
- Bouton de retour en haut de page
- Affichage automatique de l'année dans le footer
- Effet de la barre de navigation au défilement
- Menu hamburger responsive
## Structure du projet

Le projet est organisé en plusieurs fichiers et dossiers :

- **index.html** : page d'accueil.
- **programme.html** : présente le programme de la conférence.
- **intervenants.html** : affiche les intervenants avec un système de filtrage.
- **contact.html** : contient le formulaire de contact, la FAQ et la carte Google Maps.
- **css/style.css** : regroupe tous les styles du site.
- **js/main.js** : contient toutes les fonctionnalités JavaScript.
- **images/** : contient les images utilisées dans le projet.
- **README.md** : présente le projet et les informations importantes.
